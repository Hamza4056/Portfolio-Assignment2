
# Portfolio Website - Assignment 2

This is my personal portfolio website created using Node.js, ExpressJS and EJS for INFR3120 - Web and Scripting Programming.

The website includes four pages: Home, About Me, Projects and Contact Me.

## Website Structure

I used Express Generator to create the structure of my website. I used EJS templates and partials for the header, navigation bar and footer, as well as Express routes to display each page.

## Responsive Design

I used three separate CSS files to make my website responsive:

- full.css for desktop screens
- tablet.css for tablet screens
- smartphone.css for smartphone screens

I also used Bootstrap and Font Awesome for the layout, styling and navigation icons.

## Color Scheme and Gradient

I kept the same color scheme from Assignment 1, using the colors from the Lecture 3 in-class full.css example.

- Cream: #F2E2CE
- Blue: #23B7D9

I used a linear gradient to create the background of my website.
